# SWarmNexus app

Carbon React runtime for GoalNexus — a method for business coordination (delegate, assess, decide, execute, compound).

Documentation is a VitePress site in `docs/`. It deploys to GitHub Pages from the `gh-pages` branch.

## App

```bash
npm install
npm run dev
```

Opens at `http://localhost:5174`.

## Docs

```bash
npm run docs:dev      # http://localhost:5173
npm run docs:build
npm run docs:preview
```

See [docs/publish.md](docs/publish.md). After Pages is enabled: https://nafiul-earth.github.io/swarm-nexus/
