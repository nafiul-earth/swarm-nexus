# VitePress docs (local)

GoalNexus-app documentation is a VitePress site. For now it is previewed locally only.

| Item | Value |
| --- | --- |
| Source | `docs/` |
| Config | `docs/.vitepress/config.mjs` |
| Dev | `npm run docs:dev` → `http://localhost:5173` |
| Build | `npm run docs:build` → `docs/.vitepress/dist` |
| Preview | `npm run docs:preview` |
| `base` | `/` |

GitHub Pages can be added later.
